# **App Name**: Systems Engineer Portfolio

## Core Features:

- System Overview: Landing page providing a high-level summary of skills and philosophy as a systems engineer.
- System Modules: Dedicated pages for auth, data, realtime, security, and scaling, detailing problem-solving approaches, architectural decisions, tradeoffs, and potential improvements.
- Collaboration Showcase: Illustrate collaboration through examples of working with other developers, learning from code reviews, and shared code ownership.
- Experiments Hub: Display work-in-progress web and mobile apps, alongside explorations into AI-assisted tools, showcasing learning and iterative development.
- Decision Log: Document important architectural and engineering decisions made during project development.
- Music Integration: Present music-related apps or experiments, emphasizing the influence of personal passion on technical projects.
- AI Content Assistant: Leverage a tool to generate starter content and suggest improvements for system module documentation, reducing initial writing effort.

## Style Guidelines:

- Dark Charcoal / Near-Black (#121212 – #1A1A1A) Perfect for dark mode by default, keeps focus on content, and gives a serious, sophisticated tech vibe.
- Cool White / Light Gray (#F5F5F5 – #EAEAEA) For text and subtle backgrounds, high contrast, readability-focused
- Electric Cyan (#00FFFF) Signals innovation, tech, AI curiosity, works well for buttons, hover states, or icons
- Vibrant Orange (#FF6B35) Adds warmth, energy, collaboration, and creativity, can highlight calls-to-action or important sections
- Deep Purple (#7B61FF) for subtle gradients or secondary accents (evokes creativity + music tech)
- Mint Green (#3DFFAB) or Neon Pink (#FF3DD2) Only small dots, tags, badges, or hover animations. Creates a sense of playful, evolving personality without breaking the professional feel
- Body font: 'Inter', a sans-serif font, for readability and a neutral, modern feel.
- Headline font: 'Space Grotesk', a sans-serif font, for impactful section titles and a techy feel.
- Use simple, line-based icons from shadcn/ui to represent system modules and key concepts.
- Implement a clean, responsive layout with a strong type hierarchy, utilizing a grid system for clear content organization.
- Employ subtle transitions and animations on page loads and interactions, maintaining a professional and polished feel.
